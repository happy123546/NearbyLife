# NearbyLife
邻探生活服务系统 — 本地生活服务后端项目

## 📖 项目简介
本项目是面向本地生活场景的后端服务系统，支持商户展示、用户登录、商品抢购、订单管理等核心业务。基于SpringBoot搭建，大量运用Redis实现缓存、分布式会话、并发控制，解决高并发、缓存击穿、超卖、暴力破解等常见线上问题。

##  技术栈
- 核心框架：Spring Boot
- 数据库：MySQL 8.x
- ORM框架：MyBatis-Plus
- 缓存中间件：Redis
- 接口调试：Apifox

##  核心功能与技术亮点
### 1. 分布式登录 & 安全防护
- 采用 **Redis + UUID Token** 实现分布式登录会话管理，自定义拦截器实现Token自动续期；
- 使用 Redis `INCR` 原子操作统计登录失败次数，连续错误5次锁定账号3分钟，防范暴力破解。

### 2. 热点商户缓存方案（高并发优化）
- 首页热点商户数据存入Redis缓存，支撑大量并发访问；
- 使用 **逻辑过期 + 互斥锁** 方案解决缓存击穿问题；
- 接口平均响应时间由700ms优化至80ms，性能提升近10倍。

### 3. AOP异步操作日志
- 基于AOP切面拦截关键接口（登录、下单等）自动记录用户操作日志；
- 使用异步线程执行日志入库，避免日志IO阻塞主线程，保障业务接口响应速度。

### 4. 商品抢购 & 防超卖方案
- Redis原子操作预扣库存，快速拦截无效请求；
- 数据库乐观锁兜底，防止商品超卖；
- 全局唯一ID生成器生成订单号，通过线程池**异步创建订单**，提升抢购接口吞吐量。
